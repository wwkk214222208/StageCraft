# ST 预设 → StageCraft 预设编辑决策手册

本手册只定义 **AI 编辑助手面对“已经导入的 StageCraft 预设”时的决策规则**。
ST 转换期的过滤（原生槽位跳过、正则总开关、采样参数等）由本地确定性导入器
`convertSillyTavernPreset` 完成，AI 助手拿到的节点已经是过滤后的结果，
**本手册不重复转换期规则**。

---

## 1. 固定玩法节点（不可动）

节点 `removable === false` 属于固定玩法组件（角色决策、草稿、角色发言、
世界导演等）。AI 不得：

- 改名、删除节点；
- 修改其 `role`（system / user）；
- 修改其内容模板；
- 将其移出所属 system / user 段。

允许：

- 调整节点顺序（同段内）；
- 建议切换启用状态。

---

## 2. 私有节点（可编辑）

非固定节点由玩家创建/导入，AI 可以提出编辑建议：

- 每个独立信息来源 = 独立节点，**不合并**；
- **不改写原文内容**（只提出改动建议，不直接替换文本）；
- 保持原始 `role` 语义：指令/设定在 system 段，玩家侧内容在 user 段；
- `enabled === false` 的节点保留，以暗色显示，**不删除**；
- 同一节点在多个情景（scenario）中出现时，改动建议需指明影响哪些情景。

---

## 3. 正则规则

- 正则规则属于 ST 兼容层，`compatibility.regexEnabled` 总开关默认关闭；
- AI 不得建议默认开启总开关；
- 可针对单条规则提出修正（pattern/replacement），但需说明其仅在总开关开启时生效。

---

## 4. 不讨论的转换期字段

以下内容在导入时已被确定性转换器处理，不在此预设中体现，AI 不主动讨论：

- ST 原生 marker 槽位（main / nsfw / worldInfo 等）——已被跳过；
- 采样参数（temperature / top_p / penalty 等）——不转换；
- `squash_system_messages`、prefill —— 不转换。

---

## 5. 输出形式

- 输出节点级 diff：新增 / 删除 / 改 role / 调顺序 / 建议启用状态，逐条注明理由；
- 不直接写入用户的 StageCraft 预设；
- 不伪造“已保存”或“已完成”；
- 不返回空对象；无改动时明确说明“无建议”。
